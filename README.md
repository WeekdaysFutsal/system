# WD_FUTSAL (웹 버전 Ver.0.7.1)

신청 → 주장·순번 → 드래프트와 채팅 → 교환 → 공지 이미지 → 경기 기록까지 한 앱에서 진행해요.
GitHub Pages로 올릴 때는 config.js에 Firebase 설정이 있어야 동작해요. (체험 모드는 없앴어요)

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 틀과 디자인 |
| `app.js` | 앱 기능 전체 |
| `config.js` | **Firebase 설정, 운영진 비밀번호, 팀 이름·색, 기본값** (여기만 고치면 돼요) |
| `assets/` | 엠블럼, 앱 아이콘 |
| `firestore.rules` | Firebase 보안 규칙 (콘솔에 붙여넣기) |
| `manifest.webmanifest`, `sw.js` | 홈 화면에 앱처럼 설치하기 위한 파일 |

## 1. Firebase 프로젝트 만들기 (약 5분)

1. https://console.firebase.google.com 접속 → **프로젝트 추가** → 이름 입력(예: `wd-futsal`) → Google 애널리틱스는 꺼도 돼요.
2. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 로그인 방법** 탭에서 **익명**을 사용 설정으로 저장해요.
3. **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)`
   - **프로덕션 모드**로 시작
   - 만든 뒤 **규칙** 탭에 `firestore.rules` 내용을 붙여넣고 **게시**해요.
4. 프로젝트 개요 옆 ⚙ **프로젝트 설정 → 일반 → 내 앱**에서 웹 아이콘(`</>`) 클릭 → 앱 이름 입력 → 등록
   - 화면에 나오는 `firebaseConfig = { ... }` 값 6개를 `config.js`의 `firebase` 부분에 그대로 옮겨요.
5. `config.js`의 `adminPin`을 원하는 운영진 비밀번호로 바꿔요.

## 2. GitHub Pages에 올리기

1. GitHub에 새 저장소를 만들고(예: `wd-futsal`) 이 폴더의 파일을 모두 올려요.
2. 저장소 **Settings → Pages → Branch: main / (root) → Save**
3. 1~2분 뒤 `https://아이디.github.io/wd-futsal/` 로 접속해요.
4. Firebase 콘솔 **Authentication → 설정 → 승인된 도메인**에 `아이디.github.io` 를 추가해요.

## 3. 멤버들에게 공유

- 링크를 단톡방에 공유하면 누구나 열 수 있어요.
- 안드로이드 크롬: 메뉴 → **홈 화면에 추가** / 아이폰 사파리: 공유 → **홈 화면에 추가** 하면 앱처럼 아이콘이 생겨요.
- 운영진과 기록 담당자에게만 운영진 비밀번호를 알려 주세요. (오른쪽 위 운영모드 버튼)

## 사용 방식

- **일반회원**: 링크를 열면 별도 선택 없이 바로 들어와요. 하단 메뉴는 홈, 일정, 결과, 기록이고 설정은 오른쪽 위 ⚙ 버튼에 있어요.
  - 홈: 위쪽 MATCH REVIEW(지난 경기 우승 팀, 순위와 승무패, 득점왕, MOM. 누르면 결과 상세), 아래쪽 NEXT MATCH(날짜, 장소, D-day, 신청 인원/정원, 진행 상태)
  - 일정: 경기별 신청 오픈, 신청 마감, 팀 발표, 경기 타임라인
  - 결과: 이전 경기 순위와 승무패, 누르면 경기별 결과, MOM, 공격포인트, 팀 명단
  - 기록: 내 기록(참가, 경기, 득점, 도움, MOM, 승률과 순위)과 득점, 도움, 공격포인트, 참가, MOM, 승률 순위표
- **운영진**: 오른쪽 위 **운영모드** 버튼을 누르고 비밀번호를 입력해요. 다시 누르면 일반 화면으로 돌아가요.
- **주장**: 운영진이 주장 단계에서 만드는 **주장 링크**로 들어와요. 링크를 열면 그 주장 이름으로 드래프트 화면에 바로 참여하고, 하단에 드래프트 탭이 추가돼요. 주장을 바꾸면 이전 링크는 쓸 수 없게 돼요.

## 진행 흐름

1. **신청**: 경기일을 만들 때 정원, 신청 오픈, 신청 마감 시간을 정해요. 카톡 투표 참여자 이름을 복사해 붙여넣으면 신청자 명단이 만들어져요. 줄바꿈, 쉼표, 번호가 섞여 있어도 이름만 골라내요.
2. **주장**: 팀별 주장을 고르고, 주장 링크를 각 주장에게 보내고, 🎲 순번 추첨(또는 ↑↓로 직접 지정) 후 드래프트 시작.
3. **드래프트**: 주장은 자기 차례에 선수를 지명할 수 있어요. 1-2-3-3-2-1 순서는 자동이고, 지명 내역은 채팅에 기록돼요. 운영진은 되돌리기가 가능해요.
4. **교환**: 운영진이 선수 한 명을 누르고 다른 팀 선수를 누르면 맞바꿔요.
5. **공지**: 매치데이 이미지가 자동으로 만들어져요. 공유 버튼으로 카톡에 바로 보내거나 저장해요. NOTICE 문구에서 `{ }` 로 감싼 글자는 노란색이에요.
6. **경기**: 9경기 일정이 만들어지고, 전반 → GK 교체 → 후반 타이머와 휘슬, 골·도움, 순위, MOM이 기록돼요.

## 알아둘 점

- 웹에서는 휘슬이 울리려면 **경기 화면을 켜 둔 상태**여야 해요. (2단계 안드로이드 앱에서 화면이 꺼져도 울리도록 만들 예정)
- 운영진 비밀번호는 간단한 잠금이에요. 링크와 비밀번호를 외부에 공개하지 마세요.
- Firebase 무료 요금제(Spark)로 클럽 규모에서는 충분해요.
